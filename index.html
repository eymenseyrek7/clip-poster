Eymen Clip Poster

Eymen Clip Poster is a small personal desktop tool. Its only user is its owner, Eymen Seyrek. It takes short vertical clips that the owner has edited from podcast episodes (with permission, as part of creator clipping campaigns) and publishes them to the owner's own TikTok and Instagram accounts.

How it works

  1. The owner edits a short clip on their own computer and reviews it in a local control panel.
  2. Only after the owner explicitly approves a clip, the tool uploads it to the owner's own account using the official TikTok Content Posting API and the Instagram API, with the caption the owner approved.
  3. The tool never posts to anyone else's account, does not collect data about other users, and does not run any ads.
